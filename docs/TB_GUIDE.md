# Guia de uso da testbench

- Top: `op_decoder_tb`
- Ferramenta: Vivado XSim 2025.1
- Rodar: `scripts/vivado/run_tb.tcl`

### Convenção de logs
- Primeiro imprime **a instrução** testada (nome + campos).
- Depois, se houver, imprime **ERROS** daquela instrução.
- Ao final: resumo com contagem de PASS/FAIL.
